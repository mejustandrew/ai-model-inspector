What can AI Model Inspector inspect?

For GGUF files, the inspector reads the header, typed metadata, and tensor descriptors. For ONNX files, it reads model properties, graph inputs and outputs, nodes, initializers, and tensor relationships.

Estimate memory before running a model

The estimator separates model weights, KV-cache memory, and a runtime allowance. Change context length and parallel sequences to see how the estimate responds.

Your model stays on your device

Parsing and optional SHA-256 hashing happen in your browser. The model file is not sent to an AI Model Inspector server. Ordinary page requests and advertising are separate; see the privacy policy.
